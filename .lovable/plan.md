# Nexus 5 NetHunter photo documentation

## Goal
Turn the existing Nexus 5 lab entry into a compact, evidence-led case study without changing the portfolio’s restrained editorial style.

## Changes
- Add the eight supplied photographs to the Nexus 5 lab only, stored through the project’s media delivery system rather than as heavy repository files.
- Preserve privacy by using the uploads without EXIF metadata and avoiding captions that infer personal details not visible in the evidence.
- Extend the project data with an ordered field-note sequence covering:
  1. manual kernel compilation,
  2. flashable kernel installation,
  3. successful NetHunter boot,
  4. inspection of the NetHunter libraries,
  5. loading the `libfakeioctl`/Nexmon hook,
  6. the interface remaining in managed mode,
  7. unavailable `nexutil` tooling in the attempted environment,
  8. `bcmdhd` driver logs and the final monitor-mode diagnosis.
- Add a reusable, accessible evidence gallery inside expanded entries: responsive image layout, numbered captions, useful alt text, lazy loading, and a full-size image viewer.
- Keep every technical statement precise: the images demonstrate the troubleshooting process and observed states, not a successful monitor-mode activation.
- Update the site’s public text index so search engines and technical readers can discover this documented lab.

## Verification
- Check the expanded Nexus 5 entry on desktop and mobile.
- Confirm every image loads, opens full-size, has readable captions, and does not break scrolling.
- Confirm keyboard operation, image alternatives, reduced-motion behavior, and a clean build.
